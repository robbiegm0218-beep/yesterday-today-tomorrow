# 昨天今天明天

记住昨天、安排今天、推进明天的个人 Agent。应用名称已更新；助手昵称仍可自定义，已有资料与配置沿用。

## macOS 个人助手

这是一款以对话为入口的本机个人助手。对话理解、计划排序和纪要分析通过 DeepSeek 官方 API 完成；聊天、记忆、项目、个人待办和资料库索引保存在本机。应用不会把本机事项伪装成钉钉事项。

## 构建与启动

需要 macOS 13+ 和 Swift 6 工具链。仓库提供 `.app` 打包脚本：

```sh
scripts/build-app.sh
open dist/昨天今天明天.app
```

核心单元测试：

```sh
scripts/test.sh
```

也可以从源码运行：

```sh
swift run
```

第一次使用可在角色设定中保存 DeepSeek API Key。Key 保存在 macOS 钥匙串，设置页不会预填或显示已保存的密钥；留空保存会保留现有密钥，替换密钥需输入新值，移除则需单独确认。“测试连接”可直接使用已存密钥，只发送简短验证文本，不发送聊天或个人上下文。模型请求失败时，界面会显示错误，不会把待办操作显示成已完成。

当前模型配置使用 DeepSeek OpenAI 兼容接口 `https://api.deepseek.com/chat/completions`，模型标识为 `deepseek-flash`；API Key 不写入配置文件，由用户在应用内输入并保存到 macOS 钥匙串。

## 已实现

- 对话为默认入口，工作台、记忆、资料库和技能分栏展示。
- DeepSeek 聊天 API、连接测试、最多 3 条稳定记忆提取及关系阶段。
- 对话请求支持手动停止等待；单次 API 请求最长等待 45 秒。网络失败可从错误消息重试原始请求；停止或超时后会说明请求可能已被服务商接收。
- 用户明确说“这件事不要记住”等中英文表达时，本机跳过该轮自动记忆提取；已有记忆不会因此删除。
- 受限模型工具：提出创建/更新/完成本地个人待办，以及创建/更新本地项目。所有写入先显示确认卡片；个人待办保存在 `~/Library/Application Support/YuanPersonalAssistant/personal-todos.json`。
- 工作台可以直接新建、编辑、完成、恢复和删除个人待办，设置截止日期、优先级、负责人和项目关联；待办写入本机后参与今日优先级排序，已完成事项可查看，删除前会二次确认。
- 会议纪要行动项经用户核对后，可加入本机个人待办继续跟进，也可复制清单到钉钉。负责人、原文截止描述和简短依据会保留；只有明确的 `YYYY-MM-DD` 会转换为日期，不推断“下周五”等相对日期。聊天请求可能把这些个人待办字段发送给 DeepSeek，设置页会明确说明发送范围。
- 四款参考用户配图生成的手绘人物头像（柔和、清爽、元气、温暖），可在角色设定中切换，侧栏与助手回复同步显示。源图与提示词见 `Resources/Avatars/README.md`。
- 角色设置中可导出本机资料 JSON、校验后恢复备份，或二次确认后清除应用本机数据和 DeepSeek Key；恢复会保留此 Mac 的 Keychain API Key，并将知识库作为可搜索快照恢复，重新授权原文件夹后才能刷新。API Key 与资料库目录安全书签不会进入导出文件。导出的 JSON 未加密。
- 本机聊天、记忆、待办、项目和资料库索引使用原子 JSON 写入并保留最近有效副本；主文件不可读取时会尝试恢复副本。无法恢复时应用会提示并阻止覆盖原文件，损坏文件保留在应用支持目录中供后续排查。
- 本期工作台默认只读取本机个人待办和项目进度，不显示 Apple 日历连接或 macOS 系统通知入口，也不申请相关权限。Apple 日历、通知和后台自动计划排在后续阶段。
- 纪要行动项提取：支持 Markdown、Word（.docx）、纯文本导入或粘贴；文件最大 8 MB、文本最多 120,000 字，长文本分段发送并校验原文依据，先展示候选供人工核对。原文仅临时载入工具窗口。
- 技能库包含内置技能和本机自定义技能，支持启停、创建、编辑与删除自定义技能；启用技能的说明会随相关对话上下文发送给 DeepSeek。
- 本地 Markdown、Word 和纯文本资料库索引与混合关键词检索，按标题、词频和文档长度排序；资料片段仅在相关对话时发送给 DeepSeek。首期不包含语义向量召回。
- 每日计划使用本机待办、项目进展和记忆进行本地排序；配置 DeepSeek 后可生成个性化排序理由。本期在工作台手动刷新，不在系统通知中投递提醒。

## 隐私与数据流

聊天请求通过 HTTPS 发送到 DeepSeek，包含最近最多 40 条对话、最多 30 条本机记忆、相关资料片段、本机待办和项目上下文，以及已启用技能的指导说明。每日计划排序会发送候选待办、最多 20 个本机项目进度和 20 条记忆；本期不读取 Apple 日历或发送系统通知。纪要提取会发送用户粘贴或导入的全文。导入文件原文只在纪要窗口临时载入，不保存到本机资料库；API Key 存在钥匙串；聊天、记忆、项目、个人待办、技能配置和资料库索引保存在本机。资料库源文件不会复制进应用数据目录。

## 钉钉待办操作

同步待办支持“去钉钉处理”和“隐藏”。无直达链接时会复制标题并打开钉钉，处理完成后刷新工作台。隐藏仅在本机生效，重启、刷新后保留；在“已隐藏的钉钉待办”可恢复。隐藏事项不进入 AI 排序、项目统计和 Agent 当前待办快照，隐藏清单随备份导出/恢复。

## 对话表达与排版

助手回复支持 Markdown 标题、重点加粗、悬挂缩进列表、编号、引用和代码块。每轮对话根据已保存的性格、语气、称呼及关系阶段生成具体表达约定，并结合本轮情绪线索调整回应；日常查询优先给出重点，不默认展开全部无截止日期待办。情绪理解不新增画像字段，语气变化不改变事实及操作确认规则。
