# 昨天今天明天

以对话为入口的 macOS 个人 Agent：记住重要的事，安排今天，推进明天。助手昵称、头像和相处风格可自定义。

> 当前本机交付：**0.2.0 · build84**（2026-11-18），已安装并启动。源码版本见 `Resources/Info.plist`。本机使用 Apple Development 签名，尚未完成公开分发所需的 Developer ID 签名和公证。

## 当前能力

- **个人对话与记忆**：DeepSeek 流式回复、停止/重试、后台记忆队列、长期偏好与任务级临时偏好。临时偏好按原运行/阶段和范围核对，结束后不从历史复活。
- **事项与今日计划**：工作台汇总本地事项及已授权钉钉来源；计划可调整后确认保存，执行安排与源事项完成状态分开。
- **目标推进**：2—4阶段方案、依赖、必要信息补充、修订和人工完成条件核对；重启沿原运行、精确ID、预算与回执恢复。
- **确认后写入**：本地待办/项目、事项进展和钉钉待办变更先生成预览或确认卡片；回复、聊天中的同意或计划勾选不能替代业务确认。
- **资料与只读查询**：本地 Markdown、Word、纯文本索引和相关片段召回；钉钉日程、待办、听记、文档与消息按原授权范围接入。Apple 日历仍延期。
- **独立定时能力**：每日计划、主动提醒与消息监听保留独立设置，不因手动刷新重复提交。

功能边界、历史真实账号验收和未复跑项目见 [验收清单](ACCEPTANCE_CHECKLIST.md)。

## build84：对话性能与上下文管理进展

- 输入框草稿状态与历史界面分离；富文本解析有界缓存，流式自动滚动节流。
- 默认呈现最近60条消息，历史双向翻页最多呈现120条；旧卡按精确消息ID定位。完整历史继续保存在本机。
- 记忆、资料与系统规则分块计量。纯寒暄减少业务背景；明确以“只解释通用概念：”开头且无任务绑定/业务冲突时，本轮不附带个人召回正文、不提供工具，也不挂载未提供资料的引用。
- 普通模型历史仍取最近最多40条消息。以“仅以本条为准：”开头可明确建立新的普通聊天历史边界，旧记录保留，任务约束与回执仍独立核对。
- 每次主对话按包含工具定义/调用/结果的完整JSON估算输入，再结合原运行剩余额度收窄输出预留；不足时发送前停止，不截断关键依据、不重置原预算。覆盖后续只读轮次、原问题续答、阶段替代及参数修复。
- 估算采用 `ceil(UTF8字节数 / 3)`，不是服务商分词器或真实用量保证。默认估算输入上限49152、请求JSON上限196608字节、输出目标预留8192；实际输出还受原请求限制及原剩余额度约束。

详见 [联合输入预算](JOINT_INPUT_BUDGET.md)、[召回子模块](RECALL_CONTEXT.md)、[背景选择](CONTEXT_SELECTION.md) 和 [历史窗口](HISTORY_WINDOW.md)。

## 构建与测试

需要 macOS 13+、Swift 6工具链及命令行开发工具；此项目不是跨平台服务。

```sh
bash scripts/build-app.sh
open "dist/昨天今天明天.app"
```

本机签名配置不在仓库中，其他机器请按 [签名设置](SIGNING_SETUP.md) 配置。已有应用请先正常退出，再覆盖同一路径。源码调试可运行 `swift run`。

```sh
bash scripts/test.sh
```

真实账号/外部模型验收需对应显式入口与本机配置；本地单元或模拟结果不能代替真实账号、语言质量和性能结论。离线应用流程入口见 [Agent评估](AGENT_EVALUATION.md) 与 `scripts/run-agent-evaluation.py --help`。

## 配置与数据

DeepSeek使用 `https://api.deepseek.com/chat/completions`，当前模型标识为 `deepseek-flash`。第一次连接可在助手设置保存Key；Key存于macOS钥匙串，不写入仓库或资料备份，设置留空保存会沿用现有Key。钉钉接入见 [DINGTALK_SETUP.md](DINGTALK_SETUP.md)，凭据由DWS管理。

聊天、记忆、本地待办、项目、技能和资料索引保存在 `~/Library/Application Support/YuanPersonalAssistant/`，使用原子JSON写入及有效副本恢复。可在设置中导出、校验恢复；导出资料未加密，源文件授权书签与Key不随资料导出。恢复后需重新授权原文件夹，后台任务不会自动继续执行。

主对话可能发送近期历史、所选背景、召回片段和技能说明至DeepSeek；每日排序、纪要分析与独立自动记忆有各自数据流，不因主对话预算策略自动停用。诊断仅记录模块体积、计数、状态及用量，不新增正文或凭据日志。通知与后台功能仍受独立开关及系统授权控制。
